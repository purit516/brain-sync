brain-sync

brain-sync is a personal, single-user application. It synchronizes its owner's own Google Drive folder (a personal notes vault) with a local copy on the owner's assistant computer, using the Google Drive API via the rclone tool and the owner's own OAuth client.

It is not a public service. It has exactly one user: the owner of the Google account that authorized it. No data is shared with, sold to, or processed for any third party.
